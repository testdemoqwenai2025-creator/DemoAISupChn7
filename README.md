## 🛡️ Guardrails

This repository is protected by the following guardrails to ensure the demo remains stable and available 24/7:

| Guardrail | Description |
|-----------|-------------|
| **Branch Protection** | Direct pushes to `main` are blocked — all changes require pull request review |
| **Required Reviews** | At least 1 approving review required before merge |
| **Status Checks** | Pages validation workflow must pass before merge |
| **Code Ownership** | Changes require approval from designated owners (see `CODEOWNERS`) |
| **Linear History** | Merge commits are blocked — only squash/rebase merges allowed |
| **Auto-Deploy** | Every merge to `main` auto-deploys to GitHub Pages within ~60 seconds |
